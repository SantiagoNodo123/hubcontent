Extensor Automático de Tokens Meta (60 Días o Permanente)

Paso a Paso: Tokens de 60 Días / Permanentes en Meta

Oficial Meta

Paso 1: Generar Token Temporal

Entra a Graph API Explorer, selecciona tu App y agrega los permisos: instagram_basic, pages_show_list, pages_read_engagement, instagram_manage_insights. Da clic en "Generate Access Token".

Paso 2: Extender a 60 Días (En 2 Clics sin programar)

Abre el Access Token Debugger de Meta. Pega el token temporal y pulsa Depurar. Baja hasta el final de la página y pulsa el botón azul "Ampliar token de acceso". Tendrás un User Token de 60 días listo para usar.

Paso 3: Obtener Token Permanente (NUNCA EXPIRA)

Copia ese token de 60 días, vuelve a Graph Explorer, pégalo en "Access Token" y haz la consulta: GET /{page_id}?fields=access_token.
